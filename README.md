# java-lotto-precourse

## 프로젝트 소개

사용자가 구입 금액을 입력하면 해당 금액만큼 로또를 자동 발행하고 입력된 당첨 번호와 보너스 번호를 기준으로 당첨 결과 및 수익률을 계산하는 콘솔 기반 애플리케이션입니다.

## 설계 목표:
1. **변경에 유연한 구조를 지향한다.**
   - 입출력과 도메인 로직을 명확히 분리하여 UI나 실행 환경이 달라지더라도 핵심 로직이 영향을 받지 않도록 설계하고자 합니다.

2. **확장성과 테스트 용이성을 고려한다.**
   - 변경 가능성이 높은 부분은 추상화하여 새로운 요구사항 추가 시에도 도메인 수정 없이 확장할 수 있는 구조를 목표로 합니다.

3. **도메인 객체는 불변하게 유지한다.**
   - 생성 시점에 유효성을 보장하고 이후 상태 변경이 불가능한 객체로 만들어 프로그램의 안정성과 일관성을 높이는 것을 목표로 합니다.

```
구입금액을 입력해 주세요.

8개를 구매했습니다.

[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개

6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 기능 목록

### 입력
- [x] 로또 구입 금액을 입력 받는다.
  - [ ] 입력이 비어있거나 공백은 예외처리 한다.
  - [ ] 숫자 외에 다른 문자가 포함되면 예외처리 한다.
  - [ ] 양의 정수가 아니면 예외처리 한다.
  - [ ] 1,000원으로 나누어 떨어지지 않는 경우 예외처리 한다.
- [ ] 당첨 번호를 입력 받는다.
  - [ ] 입력이 비어있거나 공백은 예외처리 한다.
  - [ ] 쉼표(,)를 기준으로 구분한다.
  - [ ] 숫자가 아니면 예외처리 한다.
  - [ ] 개수가 6개가 아니면 예외처리 한다.
  - [ ] 로또 번호의 숫자 범위를 벗어나면 예외처리 한다.
  - [ ] 숫자가 중복되면 예외처리 한다.
- [ ] 보너스 번호를 입력 받는다.
  - [ ] 입력이 비어있거나 공백은 예외처리 한다.
  - [ ] 숫자 외에 다른 문자가 포함되면 예외처리 한다.
  - [ ] 로또 번호의 숫자 범위를 벗어나면 예외처리 한다.
  - [ ] 당첨 번호와 중복되면 예외처리 한다.

### 출력
- [ ] 발행한 로또 수량 및 번호를 출력한다.
  - [ ] 각 로또 번호는 오름차순으로 정렬하여 출력한다.
- [ ] 등수별 당첨 개수와 상금을 출력한다.
- [ ] 총 수익률을 출력한다.
  - [ ] 수익률은 소수점 둘째 자리에서 반올림하여 "%"와 함께 출력한다.

### 도메인(핵심 로직)
- [ ] 로또 번호의 숫자 범위는 1~45까지이다.
- [ ] 로또 1장의 가격은 1000원이다.
- [ ] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- [ ] 당첨은 1등부터 5등까지 있다.
  - 1등 : 6개 일치 / 2등 : 5개+보너스 / 3등 : 5개 / 4등 : 4개 / 5등 : 3개
- [ ] 로또 구입 금액에 해당하는 만큼 로또를 발행한다.
- [ ] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 구한다.

### 예외 처리
- [ ] 예외가 발생하면 [ERROR] 메시지" 형식의 에러 메시지를 출력한다. 
  - [ ] 에러가 발생한 곳부터 입력을 다시 받는다.

## 설계 구조 및 책임 분리
본 미션은 로또 구입부터 결과 출력까지의 과정을 입력, 검증, 도메인, 출력의 네 영역으로 분리하여 설계하였다.   
각 객체는 자신의 역할에만 집중하며 외부 의존을 최소화해 변경에 유연한 구조를 가진다.

- `InputView` / `OutputView`   
사용자와의 입출력만 담당한다.


- `Money` / `WinningNumbers` / `BonusNumber`   
입력값의 유효성을 검증하여 프로그램의 안정성을 확보한다.


- `Lotto` / `Lottos` / `LottoIssuer`   
로또 생성과 관련된 핵심 도메인이다. `LottoIssuer`이 `Money`를 기반으로 로또를 발행하며 `Lottos`는 발행된 로또들을 관리한다.


- `LottoResult` / `Rank`   
당첨 번호와 비교하여 등수를 계산하고 수익률을 산출한다.


- `LottoNumberGenerator`  
중복되지 않는 난수를 생성하는 책임만 가진다. 로또 생성 로직과 독립적으로 교체 가능한 구조로 설계하였다.
